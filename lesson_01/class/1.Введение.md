### JSON

JSON — это текстовый формат с парами «имя: значение». Приложение получает данные и распределяет их по своим экранам: где-то выводит надпись, а где-то меняет цвет элемента. Сервис передаёт данные, но не определяет, как приложение должно их отобразить.

## Бизнес-логика

### Уровень API

Задача этого уровня — разобрать запрос, проверить его формат, вернуть результат и понятный код ответа. Здесь не принимаются бизнес-решения о том, можно ли выполнять операцию, — уровень отвечает только за приём и передачу данных.

### База данных

Заказ не хранит почту покупателя напрямую — он содержит идентификатор пользователя. Например, для заказа № 42 сохраняются идентификаторы заказа и покупателя, а почта и остальные сведения находятся в отдельной записи пользователя.

## Контракт и почему его нельзя менять

### Договор

Бэкенд-разработчик определяет, какие ссылки, адреса и запросы можно использовать. Условия контракта должны соблюдаться всеми участниками разработки, чтобы не создавать путаницу.
