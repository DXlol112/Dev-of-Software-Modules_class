# Text Kit

Учебный набор функций: обработка строк, расчёт статистики, проверка почты,
телефонов и паролей, работа с датами. Нужен Python 3.10 или новее;
внешних зависимостей нет.

## Запуск и тесты

Команды выполняются из папки `lesson_03/hw/text-kit`:

```powershell
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` можно использовать `py`, если он доступен.
Тесты: **19 проверок, OK**.

## Разделение функций

- `app/utils/text.py` — пробелы, сокращение текста, инициалы и адрес страницы.
- `app/utils/dates.py` — чтение, оформление и сравнение дат.
- `app/services/statistics.py` — среднее, медиана, разброс и подсчёт значений.
- `app/services/validation.py` — учебные проверки почты, телефона и пароля.
- `app/main.py` — примеры данных и вывод; `tests/` — проверки четырёх модулей.
- `__init__.py` — файлы пакетов; в `services` и `utils` также перечисляют экспортируемые функции.
- `README.md` — назначение, структура и команды запуска.
