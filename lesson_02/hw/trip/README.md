# Учёт расходов в поездке

Программа рассчитывает общую сумму и среднюю величину расходов в поездке.

Выполните в PowerShell из папки `lesson_02/hw/trip`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -X utf8 trip.py
```

Программа печатает отчёт

```text
ОТЧЁТ ПО ПОЕЗДКЕ
--------------------------------
записей: 10
всего потрачено: 7900 ₽
средняя трата: 790.00 ₽
```
