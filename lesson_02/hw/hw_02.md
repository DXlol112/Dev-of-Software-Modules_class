# Домашнее задание №2 — lesson_02

## Что надо сделать

В личном репозитории дисциплины создайте lesson_02/. Не изменяйте lesson_01/.
Продолжите Student Tools: добавьте расчёт минимальной и максимальной оценки.
В services/calculator.py добавьте calculate_min и calculate_max; для пустого списка
обе функции должны вызывать ValueError. В utils/formatter.py оформите понятный
отчёт. В main.py соедините расчёты и выведите результат через Rich.
Для [5, 4, 5, 3, 5]: средняя 4.40, минимальная 3, максимальная 5.

Состав: app/ с пакетами, tests/, .gitignore, requirements.txt, README.md.
В README: имя, группа, назначение, версия Python, структура и обязанности файлов,
команды создания и активации .venv для вашей ОС, установки зависимостей, запуска
и тестов, ожидаемый результат. Добавьте реальный вывод sys.executable и версии
Python, объясните своими словами, почему окружение не входит в репозиторий.

Добавьте четыре теста для новых функций: обычный список и пустой список для каждой.
Тесты пишутся обычными функциями с assert и запускаются командой python -m pytest -v.
Сохраните три исходных теста: всего должно проходить не менее семи тестов.
Проверьте проект после скачивания в отдельную папку с новой .venv.
Сохраните в README команды проверки и результат.
В Git не должны попасть .venv/, __pycache__/, .env.

Сдача: ссылка на папку lesson_02 в вашем репозитории GitHub.
Критерии: структура 2, воспроизводимый запуск 2, расчёты и ошибки 2,
тесты 2, README и чистота Git 2. Максимум 10 баллов.
